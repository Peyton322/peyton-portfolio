# Peyton 陳家敏｜作品與研究

個人履歷與作品集網站，包含研究、作品、實務經歷與聯絡方式。

## 本機查看

用瀏覽器開啟 index.html。網站無需安裝套件。

## GitHub Pages

將本資料夾的 index.html、peyton-graduation.jpg及 .nojekyll 放在儲存庫根目錄。
在 Settings → Pages 選擇 Deploy from a branch，指定 main 分支與 /(root)，然後 Save。

官方說明：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 更新

修改 index.html 後提交至 main，GitHub Pages 會重新發布。
照片使用相對路徑 peyton-graduation.jpg，可相容專案型 GitHub Pages。
